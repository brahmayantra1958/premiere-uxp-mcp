Premiere UXP MCP operating contract 1.0.0.
Read premiere://guide/contract and only the relevant resources listed by resources/list. The connected tools/list schema is authoritative for arguments and profiles.
For first installation/settings use premiere://guide/setup-checks; for connection/update/Reload errors use premiere://guide/reload-checks and premiere://guide/operator-runbook. Reconnect stdio for profile/guidance changes; drain work before restarting an owner whose code/settings changed. UDT code-only uses Reload, manifest changes Unload/Load; CCX/helper updates follow their own installation lifecycle. Personal skills refresh separately. Do not start recovery during healthy editing.
Start target discovery with get_agent_context; use its current project/sequence IDs to pin subsequent work. Check premiere_ping deployment and get_mutation_recovery before the first edit. A ready connection or installed skill does not authorize unrelated edits.
Before source-range placement inspect get_agent_context.placementCapabilities; older servers require get_capabilities.write.sourceRangePlacement:true explicitly. Panel version and tool schema do not prove live support. Keep full-original media regardless of route. A full-original placement followed by trim_clip_exact is a conditional alternative only when both capabilities are present and the entire temporary source placement is empty on every inserted stream. Compute the temporary position for a coupled head trim, refresh exact guards and verify the final range. Never auto-fallback, pre-cut files, or reload/deploy during ongoing editing to bypass a refusal.
Preserve the user's requested timing, audio, effects and future editability. Keep source framing intact and use Premiere Motion for ordinary reframing; bake crop/rotation only when the requested result requires it. Respect an explicit scale even when it cannot fill the frame, and explain the difference.
Prefer bounded query_timeline/query_media, exact selectors, pagination and parameter detail. Prepare tools do not execute edits. Refresh changed IDs, indices and cursors after edits.
Combine same-effect parameters; submit supported repeated work once as a bounded job. Native writes are sequential. Wait with wait_runtime_events, then inspect cached terminal receipts; acceptance is PARTIAL and events are not proof.
Check content readback and requested preservation. Use capture_program_frame for composited images; visual composition, audio quality and native panel visibility need their corresponding evidence. Avoid redundant reads already proven by receipts.
Overview and verification reads retain the last work location. Targeted reads/edits follow their target. Ordinary follow failures do not change content status; explicit UI operations and specialized native proof retain their own checks. Do not restore focus/playhead unless requested.
A timeout after dispatch is UNVERIFIED. Wait for active work; inspect affected state before any corrected edit. archive_inactive_operation can release only an inactive exact root operation without replay or restoration; its old receipt remains unchanged. Use reconcile_mutation when adjudicating that old result. Never delete locks or replay unknown work with a new UUID.
Use explicit absolute media inputs read-only; generated artifacts stay in allowed output/proxy/scratch roots. Saved local projects need no WORKING__ prefix or project allowlist. Use existing declared UXP/IPC/bounded native routes; do not invent arbitrary CEP/QE/script/input bypasses.
Verify feature dependencies/platform and actual deployment rather than treating a source build as live support. Reuse the runtime; do not rebuild/restart during ordinary editing. Computer Use is conditional: initialize only for actual UI work and release owned resources before non-UI work/waits.
Report PASS/PARTIAL/FAIL/UNVERIFIED/UNSUPPORTED for the requested results. Retain exact target IDs, operation/job IDs and evidence needed for continuation without copying them into future jobs.
