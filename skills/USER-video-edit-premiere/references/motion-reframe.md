# 모션과 편집 가능한 재구도

원본 전체 화면과 사용자가 후속 조절할 수 있는 Motion 값을 보존한다. 세로 시퀀스 요청은 소스를 세로로 미리 잘라 굽는 요청으로 해석하지 않는다. 프록시/코덱 변환이 필요해도 공간 크롭·회전을 함께 적용하지 않는다. 구도를 굽는 결과가 명시됐을 때는 별도 파생 출력으로 만든다.

1. 소스 규격·픽셀 종횡비·회전·내장 검은 여백·현재 Motion/키·추가 기하 효과를 확인한다.
2. fill(잘리더라도 꽉 채움), fit(전체 화면 표시), 사용자가 지정한 scale을 구분한다.
3. scale_clip_to_fill은 square source/sequence pixels, 중앙·무회전·무크롭 정적 Motion, 추가 geometry effect 없음 조건에서 균일 확대를 계산하고 검증한다. source bounds 채움이며 검은 여백/투명 픽셀 제거 또는 인물 중심 구도를 보장하지 않는다.
4. 인물별 위치/기준점과 지정 비율은 관측한 Motion component/parameter에 set_transform 또는 set_effect_values를 사용한다. 애니메이션이 있으면 keyframe 경로를 쓴다.
5. 화면 채움과 명시한 50% 등이 충돌하면 지정값을 적용하고 빈 영역을 알린다. scale의 UI 표시값과 native 저장 단위를 descriptor로 확인한다.
6. 결과 프레임에서 얼굴·주요 행동·자막 가림을 보고, 원본 source 영역·타이밍·오디오 보존을 별도로 검사한다.

원본 규격/효과가 달라졌으면 fill 계산을 재사용하지 않는다. 소스 교체는 현재 tools/list의 지원 경로를 확인한다. 전용 교체 도구를 가정하거나 삭제→재배치를 자동 기본값으로 삼지 않는다. 필요한 재배치는 정확한 소스 범위·컷·효과·키·A/V 관계의 보존 계획과 각 단계 readback을 갖춘다.
